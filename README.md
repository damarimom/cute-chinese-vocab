# 🍓 말랑 중국어 단어장

삐클이 만든 귀여운 중국어 단어장 웹페이지예요.

- 카드를 누르면 뒤집혀서 뜻이 보여요
- 발음 듣기 버튼으로 소리를 들을 수 있어요
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있어요
